## 一、项目是什么

基于 **Tauri 2 + React 19 + Node sidecar** 的 AI 编程助手桌面端。底层真实 AI 引擎是 **PI（@earendil-works/pi-coding-agent）**——本程序不实现任何 AI 逻辑，只是把「终端 PI」包一层桌面 UI，通过 JSONL over stdio 与 sidecar 通信。

- 目录：`L:\projects\PI-GUI`
- 当前版本：**0.6.7**（每个功能批次一个版本号，已发布到 GitHub Releases）
- Git：`main` 分支，已推送 GitHub；Release 页有全部安装包

## 二、技术栈

- 前端：React 19 + TypeScript + Vite + zustand（状态）+ react-markdown（渲染）+ @tanstack/react-virtual（消息虚拟化）
- 桌面壳：Tauri 2（`decorations:false` 自定义标题栏、`transparent` 圆角窗口）
- 驱动层：Node sidecar（`drivers/sidecar/sidecar.mjs`），JSONL over stdin/stdout
- 打包：NSIS（setup.exe）+ MSI，per-user 安装到 `%LOCALAPPDATA%\PI Agent`
- 插件：tauri-plugin-opener / dialog / global-shortcut；tauri features: devtools + tray-icon

## 四、完整功能清单（v0.6.7）

### 对话
- 流式对话、思考过程（折叠）、图片粘贴多模态、↑/↓ 输入历史（200 条持久化）
- 消息 hover 操作：复制 / 重发 / 保存 MD / 引用（插入输入框）/ 编辑（fork 重发）
- 多选模式：勾选 → 复制 / 导出 MD / 导出 HTML / 全选
- 长会话虚拟化（react-virtual 无缝滚动，万条消息流畅）
- 无响应诊断（10s 无事件才提示）+ 临时错误自动重试（2 次指数退避）

### 会话 / 项目
- 项目树（置顶/重命名/删除/拖放添加）、会话树（按项目分组）、未分类对话
- 会话树面板：「继续」（切回分支点）/「分支」（fork 新链）/「克隆当前」/ 当前叶高亮
- 压缩上下文（手动 + 自动压缩/自动重试）、payload 预警（4MB/8MB）
- 全局搜索会话内容（侧栏搜索框）、会话自动命名（firstMessage 显示）

### 并行与恢复
- 多对话池（每对话独立 AgentSessionRuntime，切项目/会话不销毁后台继续）
- 侧栏工作区双视图：项目 / 进行中（状态点、关闭按钮）
- 重启恢复对话池（aiwb:dlg-pool）、sidecar 崩溃自动重启（Rust 监督循环 + 前端重连）

### 模型 / 认证
- 模型切换、思考级别、默认模型持久化、模型列表过滤未认证 provider
- API Key 管理（auth.json 共享）、候选 Key 列表、订阅登录 OAuth（Claude/ChatGPT/Copilot）
- 自定义 Provider（models.json：Ollama/LM Studio/网关，重启生效）

### 数据管理
- 导出：MD / JSONL（可导入）/ HTML（带样式页面）/ TXT；自动保存双备份（MD+JSONL）
- 导入会话（jsonl → 打开继续）、分享为 GitHub Gist（公开/私密）

- 用量统计（近 14 天柱状图 + 汇总；v0.7 加按模型拆分）

## 五、核心协议（sidecar JSONL）

stdin 指令 / stdout 响应（`{"type":"response","requestId","command","success","data"}`）+ 事件（`{"type":"event","dialogueId","event"}`）。

命令集（44 个）：`abort activate_dialogue auth_input backup_sessions check_pi_update cleanup_sessions close_dialogue compact create_gist cycle_model defaultModel defaultProvider defaultThinkingLevel delete_project delete_session diagnostics download_pi_update exit export_session follow_up fork get_available_models get_commands get_context_files get_core_version get_messages get_providers get_session_stats get_settings get_state get_tree hideThinking init list_all_sessions list_custom_providers list_dialogues list_projects list_sessions login login_abort new_session open_dialogue prompt read_file reload_resources remove_provider search_files search_sessions session_stats_history set_api_key set_model set_session_name set_setting set_thinking_level steer switch_project switch_session`

要点：
- **open_dialogue = 初始化**（替代旧 init）：loadAll 启动时自动发；recent 会话复用检查（sessionPath 匹配则激活返回）
- 串行队列 STATEFUL_COMMANDS 保证切换/发指令顺序；`abort/exit/auth_input/login_abort` 绕过队列立即执行（否则与挂起 login 死锁）
- `closeUnfinishedToolCalls`：恢复会话时关闭遗留未完成 toolCall（防 heredoc 卡死重试）
- cwd 兜底：get_state/open_dialogue 用对话自身 cwd（SessionManager.open 从 header 恢复）
- 事件带 dialogueId，前端按当前对话过滤后台流式

## 六、踩坑记录（重要）

1. **`\\?\` 路径前缀**：Windows resource_dir 返回 verbatim 路径，sidecar import PI 崩。Rust `clean_path()` 去掉。
2. **sidecar 黑窗**：spawn 加 `CREATE_NO_WINDOW`。
3. **副本不同步**：`src-tauri/resources/.../sidecar.mjs` 必须手动 cp（打包用副本）。
4. **会话恢复卡死**：中断遗留的未完成 toolCall 会在恢复后重试（heredoc 等 stdin 命令永久挂起）→ `closeUnfinishedToolCalls` 注入 toolResult 关闭。
5. **项目形同虚设**：对话池重构后前端从不发 open_dialogue → sidecar「尚未 init」拒绝一切 → loadAll 启动自动 open_dialogue + recent 复用修复。
6. **package.json 路径**：PI 内核版本读 `dist/../package.json`（dist 上一级）。
7. **auth_input 死锁**：login 挂起时若排队会被自己阻塞 → auth_input/login_abort 立即执行。
8. **`nul` 文件**：Git Bash 下 `> nul` 会创建真实文件，`git add -A` 报错 → 删 `./nul`。
9. **gist 上传/gh 发布**：大文件上传用 curl + 长超时可靠；gh release create 不带 --json；token 从 `git credential fill` 取（execSync 用 input 方式）。
10. **makensis 偶发锁**：连续 build 时 nsis 输出文件被占用 → 等锁/重试即可。
11. **get_available_models**：不要 await 网络刷新（`mr.getAvailable()` 会阻塞），用 `mr.getModels()` 同步快照 + 后台触发刷新，前端有重试兜底。
