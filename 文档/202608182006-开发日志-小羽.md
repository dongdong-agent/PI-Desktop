## 一、项目定位（定稿）

**PI Agent** = 真 PI 终端的桌面图形客户端。
- 内核：直接内嵌 `@earendil-works/pi-coding-agent`（全局 0.84.2），与终端**同一个 Agent、同一份配置、同一份会话文件**
- 哲学：**不做任何 AI 逻辑复刻**——干活的全是真 PI，桌面端只是换了一层皮（GUI 壳）
- 愿景：在此之上叠加技能库/皮肤/桌面宠物/素材库等差异化能力

## 二、技术栈与架构（定稿）

```
WebView UI (React 19 + TS + Vite)
   │  Tauri IPC（invoke + pi_event 事件）
Rust PiBridge (src-tauri/src/pi_bridge.rs)
   │  spawn + stdio JSONL
Node Sidecar (drivers/sidecar/sidecar.mjs)  ← 内嵌真实 PI SDK
   │
真实 AgentSession（复用 ~/.pi/agent 全部配置/会话）
```

- 桌面壳：**Tauri 2**（Rust + WebView2），轻量（安装包 2MB）
- 状态：zustand；事件流：自定义 EventBus；测试：vitest（14/14）
- 协议：sidecar JSONL over stdio（stdin 指令 / stdout 事件+响应）
